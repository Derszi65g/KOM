# Variable

> [!ABSTRACT] Definición Mínima
> Una **variable** es un símbolo (generalmente una letra como $x$, $y$, $u$) que representa una cantidad numérica susceptible de tomar distintos valores o cuyo valor aún no se ha determinado (incógnita).

---

### Expresiones Tratadas como una Variable
Una variable no tiene por qué ser solo una letra simple. En álgebra podemos tomar **bloques enteros** y tratarlos como una sola variable auxiliar:
* Si $u = (x + 3)$, entonces $5(x + 3) = 5u$.
* Si $w = \frac{a+b}{c}$, entonces $2\left(\frac{a+b}{c}\right) = 2w$.

Esta técnica de "cambio de variable" permite reducir expresiones complejas a formas lineales intuitivas.

# 03.1 - Métodos de Factorización y Productos Notables

> [!ABSTRACT] El Objetivo de la Factorización
> Multiplicar es transformar factores en términos: $(a+b)(a-b) \to a^2 - b^2$.  
> **Factorizar** es la operación inversa: tomar una suma o resta de términos y reescribirla como un **producto de factores**.  
> Se factoriza principalmente para dos cosas: **poder simplificar fracciones algebraicas** (cancelando factores comunes) y **resolver ecuaciones** mediante la propiedad del producto cero ($A \cdot B = 0 \iff A = 0 \lor B = 0$).

---

## 1. Mapa de Ida y Vuelta: Desarrollo vs. Factorización

Cada caso de factorización no es más que una identidad de multiplicación leída en reversa:

| De Factores a Términos (Desarrollo / Multiplicación) | De Términos a Factores (Factorización) | Nombre del Método |
|---|---|---|
| $a(b + c) = ab + ac$ | $ab + ac = a(b + c)$ | **Factor Común** |
| $(a + b)(a - b) = a^2 - b^2$ | $a^2 - b^2 = (a + b)(a - b)$ | **Diferencia de Cuadrados** |
| $(a \pm b)^2 = a^2 \pm 2ab + b^2$ | $a^2 \pm 2ab + b^2 = (a \pm b)^2$ | **Trinomio Cuadrado Perfecto** |
| $(x + m)(x + n) = x^2 + (m+n)x + mn$ | $x^2 + sx + p = (x + m)(x + n)$ | **Trinomio de la forma $x^2+sx+p$** |

---

## 2. Los Métodos Fundamentales

### Método 1: Factor Común (Deshacer la Distributiva)
Es el primer método a intentar siempre. Se busca qué número o letra divide exactamente a **todos** los sumandos.

* **Fórmula**:
  $$ab + ac = a(b + c)$$
* **Ejemplo**:
  $$6x^3 + 9x^2$$
  * Coeficientes: el máximo divisor común entre $6$ y $9$ es $3$.
  * Letras: la menor potencia común es $x^2$.
  * Extraemos $3x^2$ y dividimos cada término:
    $$6x^3 + 9x^2 = 3x^2(2x + 3)$$

---

### Método 2: Diferencia de Cuadrados
Aparece cuando tenemos **dos términos cuadráticos restándose**.

* **Fórmula**:
  $$a^2 - b^2 = (a + b)(a - b)$$
* **Justificación**: Al hacer la multiplicación distributiva $(a+b)(a-b)$, los productos cruzados $+ab$ y $-ba$ se anulan entre sí:
  $$(a+b)(a-b) = a^2 - ab + ba - b^2 = a^2 - b^2$$
* **Ejemplo**:
  $$x^2 - 16 = x^2 - 4^2 = (x + 4)(x - 4)$$

> [!WARNING] Suma de Cuadrados
> Una **suma** de cuadrados como $x^2 + 16$ **no se puede factorizar en los números reales** ($\mathbb{R}$). La factorización exige resta.

---

### Método 3: Trinomio Cuadrado Perfecto (Inverso del Cuadrado de Binomio)
Es el camino inverso desarrollado en [[03 - Cuadrado de un Binomio]]. Un trinomio proviene de elevar un binomio al cuadrado si tiene dos cuadrados y su término central es el doble producto.

* **Fórmula**:
  $$a^2 + 2ab + b^2 = (a + b)^2$$
  $$a^2 - 2ab + b^2 = (a - b)^2$$
* **Cómo detectarlo**:
  Tomemos $x^2 + 6x + 9$:
  1. Primer cuadrado: $x^2 \to a = x$.
  2. Segundo cuadrado: $9 = 3^2 \to b = 3$.
  3. Verificamos el término central: $2ab = 2 \cdot x \cdot 3 = 6x$ (coincide exactamente).
  4. Por lo tanto:
     $$x^2 + 6x + 9 = (x + 3)^2$$

---

### Método 4: Trinomio de la Forma $x^2 + sx + p$ (Suma y Producto)
Cuando el trinomio no es cuadrado perfecto (el término del medio no es $2ab$), buscamos dos números $m$ y $n$ tales que:
* Su **suma** sea el coeficiente lineal: $m + n = s$.
* Su **producto** sea el término independiente: $m \cdot n = p$.

* **Fórmula**:
  $$x^2 + sx + p = (x + m)(x + n)$$
* **Ejemplo**:
  $$x^2 + 5x + 6$$
  Buscamos dos números que multiplicados den $6$ y sumados den $5$:
  * $2 \cdot 3 = 6$
  * $2 + 3 = 5$
  Los números son $+2$ y $+3$:
  $$x^2 + 5x + 6 = (x + 2)(x + 3)$$

## 3. Aplicaciones Prácticas

### Aplicación A: Simplificación de Fracciones Algebraicas
Simplificar:
$$\frac{x^2 - 25}{x^2 + 8x + 15}$$

1. Factorizamos numerador (Diferencia de cuadrados):
   $$x^2 - 25 = (x + 5)(x - 5)$$
2. Factorizamos denominador (Trinomio suma y producto: $3 \cdot 5 = 15$ y $3 + 5 = 8$):
   $$x^2 + 8x + 15 = (x + 5)(x + 3)$$
3. Cancelamos el factor común global $(x + 5)$ mediante el neutro multiplicativo:
   $$\frac{(x + 5)(x - 5)}{(x + 5)(x + 3)} = \frac{x - 5}{x + 3} \quad (x \neq -5, x \neq -3)$$

---

### Aplicación B: Resolución de Ecuaciones Cuadráticas sin Bhaskara
Resolver:
$$x^2 - 7x + 12 = 0$$

Factorizamos el trinomio buscando dos números que multiplicados den $+12$ y sumados den $-7$:
* $(-3) \cdot (-4) = +12$
* $(-3) + (-4) = -7$

Reescribimos la ecuación en forma factorizada:
$$(x - 3)(x - 4) = 0$$

Aplicando la **propiedad del producto cero**:
$$x - 3 = 0 \implies x = 3$$
$$\text{o bien}$$
$$x - 4 = 0 \implies x = 4$$
